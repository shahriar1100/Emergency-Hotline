🧾 Project Title
# Emergency Service Directory

📌 Description
A responsive emergency service directory web app where users can quickly call services, copy numbers, 
and track call history. The app includes coin-based calling logic and interactive UI features.

🚀 Features
- 📞 Call button shows alert with service name & number
- 💰 Each call deducts 20 coins
- ⚠️ Prevents calling when coins are below 20
- ❤️ Heart icon increases navbar count (one-time per card)
- 📋 Copy button copies service number to clipboard
- 🔢 Copy count tracking in navbar
- 🕒 Call history log with timestamp
- 🗑️ Clear call history feature

🛠️ Technologies Used
- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (DOM Manipulation)

🧠 Key Concepts
- Event Delegation & DOM Traversal (closest, querySelector)
- Conditional Logic (coin validation)
- Clipboard API (copy functionality)
- Dynamic DOM Manipulation (call history)
